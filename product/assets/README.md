# Assets

Put the files the image model should use as references here. They are uploaded to Genviral as reference images when a brief asks for them.

| File | What it is |
|---|---|
| `app-icon-1024.png` | App icon, 1024x1024 PNG |
| `logo.png` | Logo or wordmark, transparent PNG |
| `screen-*.png` | Real App Store screenshots or raw app screens |

Rules:
- Use real screens only. The factory never asks the model to invent app UI.
- PNG, JPG or WebP. Keep each file under 50 MB.
- This folder is gitignored by default so your assets stay private.
